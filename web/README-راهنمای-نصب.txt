اسلایسر Benchy Print — راهنمای نصب روی هاست cPanel
=====================================================

این اسلایسر کاملاً سمت کاربر (داخل مرورگر بازدیدکننده) اجرا می‌شود.
هیچ پردازشی روی سرور انجام نمی‌شود؛ PHP، دیتابیس و رم/سی‌پی‌یو سرور مصرف نمی‌شود.
حجم کل: حدود ۱٫۳ مگابایت.

محتویات این پوشه
----------------
index.html        صفحهٔ اسلایسر
lib/              three.js r128، JSZip 3.10، Clipper 6.4.2 (به‌صورت محلی، بدون CDN)
fonts/            وزیرمتن و JetBrains Mono (به‌صورت محلی، بدون Google Fonts)
.htaccess         فشرده‌سازی و کش فایل‌ها

مراحل نصب
---------
1. در cPanel وارد File Manager شوید و به پوشهٔ public_html بروید.
2. یک پوشه به اسم slicer بسازید (یا هر اسم دیگری).
3. فایل benchy-slicer-web.zip را داخل همان پوشه آپلود کنید و Extract بزنید.
   دقت کنید فایل‌های مخفی (.htaccess) هم کپی شوند.
4. آدرس صفحه می‌شود: https://دامنهٔ-شما/slicer/
5. از بخش SSL/TLS Status در cPanel، گواهی رایگان (AutoSSL) را برای دامنه فعال کنید؛
   صفحه باید با https باز شود.

نکته‌ها
-------
- چون همهٔ کتابخانه‌ها و فونت‌ها روی هاست خودتان است، صفحه در ایران بدون فیلترشکن کار می‌کند.
- سرعت برش به سیستم بازدیدکننده بستگی دارد، نه سرور شما.
- G-code مستقیم با پسوند .gcode دانلود می‌شود؛ آن را روی کارت حافظهٔ پرینتر بریزید.
- تنظیمات و قیمت‌ها در مرورگر هر کاربر جداگانه ذخیره می‌شود.
